# 🇰🇷 HanQ Frontend
> 한국의 생활·문화 정보를 학습할 수 있는 RAG 기반 외국인을 위한 한국 정착 지원 서비스 **HanQ**의 프론트엔드 저장소입니다.
> 본 프로젝트는 Flutter로 구현된 모바일 애플리케이션으로, 백엔드 API와 연동하여 퀴즈 학습, 정보 열람, 학습 현황을 사용자 인터페이스로 제공합니다.
> 본 프로젝트는 중앙대학교 소프트웨어학부 **2025_02 캡스톤 프로젝트** 수업 산출물입니다.

---

## ⭐ 주요 기능

| 기능             | 설명                                               |
| -------------- | ------------------------------------------------ |
| 👤 사용자 인증 및 설정 | 회원가입·로그인을 통해 사용자 세션을 관리, 난이도와 하루 학습량 설정 가능 |
| 🧩 퀴즈 학습       | 서버 API와 연동하여 사용자 설정에 맞는 퀴즈를 불러와 문제를 제공  |
| 📝 퀴즈 풀이 UI    | 객관식 문제와 선지를 렌더링하고, 선택 결과에 따라 정답/오답 피드백 제공  |
| 🧠 학습 결과 반영    | 퀴즈 풀이 결과를 서버로 전송하여 학습 기록 및 티어 산정에 반영    |
| 📊 학습 현황 시각화   | 일별 학습량, 정답률 등을 차트로 시각화하여 학습 진행 상황 제공    |
| 📚 생활·문화 정보 제공 | 생활·문화·사회 정보 콘텐츠를 카테고리별 리스트 및 상세 화면으로 제공  |
| ⚙️ 설정 관리       | 사용자 설정(난이도, 학습량)을 변경하고 앱 전반에 반영    |


## 📂 디렉토리 구조

lib/

 ├── api/          # 백엔드 REST API 통신 로직
 
 ├── dto/          # API 요청/응답 데이터 모델
 
 ├── screens/      # 화면 단위 UI 구성
 
 ├── widgets/      # 재사용 가능한 공통 UI 컴포넌트
 
 ├── router.dart       # go_router 기반 화면 라우팅 관리
 
 ├── info/         # 로그인 사용자 및 전역 상태 관리
 
 └── main.dart     # 애플리케이션 진입점

## 🚀 실행 방법

### 0️⃣ 저장소 클론
git clone https://github.com/jinha0907/2025_02_CapstoneProject.git

cd 2025_02_CapstoneProject


### 1️⃣ 환경 설정
- **Flutter SDK** 설치 
- **Android Studio** 설치
- **Android 에뮬레이터** 실행 또는 **실제 기기** 연결 (개발자 모드 활성화 필요)

### 2️⃣ 패키지 설치
프로젝트 루트 경로에서 의존성 패키지를 설치합니다.

flutter clean

flutter pub get

### 3️⃣ 빌드 및 실행
앱을 디버그 모드로 실행합니다. (에뮬레이터나 기기가 연결되어 있어야 합니다.)

bash flutter run

성능 테스트가 필요하거나 배포 환경과 동일하게 실행하려면 릴리즈 모드로 실행하세요.

bash flutter run --release

---

### 💡 추가 팁 (선택 사항)
만약 특정 플랫폼(Android/iOS)을 지정해서 실행하고 싶다면 다음 명령어를 사용할 수 있습니다.

연결된 기기 목록 확인

flutter devices

특정 기기에서  실행 ( ex : test1)

flutter run -d test1
